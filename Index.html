Uso de la API de OpenAI desde la terminal

Guia practica para instalar la libreria, configurar la API Key, enviar prompts, recibir codigo como respuesta y automatizar tareas de programacion.

Instalacion API Key Terminal Prompts Automatizacion

1. Instalar la libreria de OpenAI

OpenAI ofrece SDK oficiales para trabajar desde Node.js y Python. Antes de instalar, verifica que tengas el entorno correspondiente.

Node.js

node -v
npm -v
npm install openai

Python

python --version
pip install openai
En Windows, si python no funciona, prueba con py --version y luego py -m pip install openai.

2. Configurar la API Key en el sistema

La API Key identifica tu cuenta y permite que los programas llamen a la API. No debe escribirse directamente dentro del codigo ni compartirse publicamente.

Windows PowerShell, solo para la sesion actual

$env:OPENAI_API_KEY="tu_api_key_aqui"

Windows PowerShell, guardada para futuras sesiones

setx OPENAI_API_KEY "tu_api_key_aqui"

macOS o Linux

export OPENAI_API_KEY="tu_api_key_aqui"

Despues de usar setx, abre una terminal nueva para que el cambio se cargue.

3. Ejecutar solicitudes desde la consola

La forma mas simple es crear un archivo y ejecutarlo desde la terminal.

Ejemplo con Node.js: archivo example.mjs

import OpenAI from "openai";

const client = new OpenAI();

const response = await client.responses.create({
  model: "gpt-5.2",
  input: "Explica en una frase que es una funcion en JavaScript."
});

console.log(response.output_text);

Ejecutalo asi:

node example.mjs

Ejemplo con Python: archivo example.py

from openai import OpenAI

client = OpenAI()

response = client.responses.create(
    model="gpt-5.2",
    input="Explica en una frase que es una funcion en Python."
)

print(response.output_text)

Ejecutalo asi:

python example.py

4. Enviar prompts y recibir codigo como respuesta

Un prompt puede pedir explicaciones, codigo, pruebas o mejoras. Mientras mas claro sea el pedido, mas util sera la respuesta.

Prompt para generar codigo

import OpenAI from "openai";

const client = new OpenAI();

const prompt = `
Crea una funcion en JavaScript llamada calcularPromedio.
Debe recibir un arreglo de numeros y devolver el promedio.
Incluye un ejemplo de uso.
`;

const response = await client.responses.create({
  model: "gpt-5.2",
  input: prompt
});

console.log(response.output_text);

Prompt mas especifico

Escribe codigo Python para leer un archivo CSV llamado ventas.csv.
Calcula el total de la columna precio.
Incluye manejo basico de errores y explica el resultado brevemente.

5. Automatizar tareas de programacion desde la consola

Tambien puedes crear scripts que reciban instrucciones desde la terminal y generen ayuda automaticamente.

Script Node.js: ask.mjs

import OpenAI from "openai";

const client = new OpenAI();
const prompt = process.argv.slice(2).join(" ");

if (!prompt) {
  console.error("Uso: node ask.mjs \"tu pregunta\"");
  process.exit(1);
}

const response = await client.responses.create({
  model: "gpt-5.2",
  input: prompt
});

console.log(response.output_text);

Uso desde la terminal:

node ask.mjs "Crea una funcion JavaScript para validar un correo electronico"

Ideas de automatizacion

  • Generar funciones a partir de una descripcion.
  • Explicar errores copiados desde la consola.
  • Crear pruebas unitarias para una funcion existente.
  • Documentar codigo y sugerir mejoras.
  • Convertir codigo de un lenguaje a otro.
